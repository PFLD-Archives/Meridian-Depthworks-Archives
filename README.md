# Meridian Depthworks Archives

![Meridian Archives Banner](Assets/HomeWiki.png)

The entire documentation for **Meridian Depthworks** — the primary source archive behind the [MDC Wiki](https://github.com/PFLD-Archives/Meridian-Depthworks-Archives/wiki). Everything here is filed in-universe, exactly as Parafield left it.

## Contents

| Directory | Holds |
|---|---|
| `S.F.R/` | Synthetic Fusion Reactor Mark I specs, fuel data, operating procedures, emergency protocols |
| `EXPERIMENTS/CONFIDENTIAL/` | Classified programs: the Vitals Initiative, the HSDR-1000, and their aftermath |
| `LOGS/` | Dated transcripts and reports, organized by year and day |

## Companion wiki

Lore synthesis, timelines, character profiles, and cross references live in the wiki, not here. Start at **Home** over there if you're new.

## Notes

* Documents dated after the 1980s are filed under the **PARAFIELD CORP** header. The company rebranded some time after the Meridian era.
* Files marked `[REDACTED]` are redacted in-universe. That's intentional.
* The `S.F.M/` project is excluded from this archive. See the Citrus Archives instead.
